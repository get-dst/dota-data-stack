  - a hero's games — the pro games the hero was picked in
  - a team's matches — the pro matches the team played

"Win rate" on its own does not say whose. A hero's win rate counts the games it was
picked in; a team's counts its matches; the Radiant win rate is a property of the map.
Each is a different number over a different denominator, so the question has to name
which one before an answer is served.
